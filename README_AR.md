# مشروع Kero Portfolio — جديد من الصفر

واجهة Portfolio مستوحاة من الفيديو المرجعي: أسود وبرتقالي نيون، مقدمة سينمائية، حركات CSS، أقسام About / Work / Capabilities / Contact ولوحة Admin.

## التشغيل
1. فك ضغط الملف وافتح مجلد `Kero-New-Portfolio` في VS Code.
2. ثبّت Node.js إذا لم يكن مثبتًا: https://nodejs.org/
3. افتح Terminal داخل VS Code وشغّل:
   `npm.cmd install`
4. شغّل الموقع:
   `npm.cmd run dev`
5. افتح الرابط المحلي الذي يظهر في الطرفية.

## لوحة التحكم
افتح `/admin` من نفس عنوان الموقع. تقدر تغيّر الاسم والوصف والبريد، ترفع صورة بروفايل وملف موسيقى، وتضيف/تعدّل/تحذف المشاريع. التغييرات محفوظة محليًا في المتصفح الحالي (localStorage).

## ملاحظات مهمة قبل النشر
- لوحة التحكم الحالية نسخة تجريبية محلية وليست محمية بتسجيل دخول حقيقي؛ لا تنشرها كما هي لموقع عام. يلزم إضافة Backend ومصادقة وصلاحيات Admin حقيقية.
- الملفات المرفوعة محفوظة داخل المتصفح الحالي؛ ليست رفعًا إلى سيرفر، وقد تكون ملفات الصوت الكبيرة أكبر من مساحة التخزين المتاحة.
- الموسيقى تبدأ بعد ضغط ENTER لأن المتصفحات عادةً تمنع التشغيل التلقائي قبل تفاعل الزائر. ارفع ملفًا تملك حق استخدامه.
- صورة البروفايل والصور والأسماء داخل التصميم قابلة للتعديل. التصميم مستوحى من اللقطات المتاحة، وليس نسخة حرفية من ملفات الموقع الأصلي.
